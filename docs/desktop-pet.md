# 水宝宝桌宠模式

水宝宝桌宠是一个独立的 Tauri Webview 窗口，复用桌面本地 JSON 的今日饮水和久坐状态，不创建第二份状态源。

- 从系统托盘菜单选择“显示 / 隐藏水宝宝桌宠”切换窗口。
- 窗口无边框、透明、置顶且不占用任务栏；按住非按钮区域可以拖动。
- 水宝宝体内水位按 `actualIntakeMl / targetMl` 显示，视觉值限制在 `0%` 到 `100%`。
- 底部数字每秒更新当前坐下或起身时长；超过 `sedentaryReminderMinutes` 后切换为暖色起身提示。
- 点击底部状态会调用现有 `toggle_sedentary_state`，主窗口、通知调度器和桌宠通过 `state-updated` 事件保持一致。
- 悬停桌宠后可打开主窗口或隐藏桌宠。
- 设置中的“启动 App 时显示水宝宝桌宠”默认开启；开启时 App 启动后自动创建并显示桌宠，关闭后仍可通过托盘菜单手动显示。该选项属于桌面本地设置，会随完整备份保存，但不进入跨设备设置快照。
